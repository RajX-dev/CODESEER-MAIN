Commercial Terms of Service

Last updated: July 2026

1. Service Overview

N3MO SaaS provides automated structural code intelligence and impact analysis for your repositories via GitHub Webhooks. By purchasing a commercial license, you gain access to team environments, CI/CD pipeline integrations, and priority indexing queues.

2. Data Ownership & Security

We believe in absolute security and transparency regarding your proprietary code:

  • You retain 100% ownership of your source code at all times.
  • Ephemeral Analysis: When using our Standard, Pro, or Team tiers, your code is analyzed on ephemeral, secure GitHub Action runners. The runner is instantly destroyed the second the Pull Request comment is posted.
  • No Raw Source Code is Stored: N3MO only stores AST graph relationships and symbol names (e.g., function definitions and caller relationships) in our PostgreSQL database to enable fast transitive traversal. Your actual source code text is never saved to our servers.
  • Zero-Trust Architecture: For Enterprise clients with strict compliance requirements, you can run the N3MO CLI completely natively inside your own private CI/CD pipelines. This ensures your code literally never leaves your Virtual Private Cloud (VPC).

3. Cancellation Policy

We don't believe in vendor lock-in. If you choose to cancel your commercial subscription:

  • Your GitHub Webhook integration will be disabled at the end of your billing cycle.
  • Your historical AST indexing data remains safely stored for a 30-day grace period in case you choose to resubscribe.
  • Local Fallback: You can continue using the open-source N3MO CLI locally on your own machine, completely free, forever.

4. Support & Service Level Agreements (SLA)

The level of support provided depends on your active tier:

  • Standard: Access to community support via Discord and GitHub Issues.
  • Pro & Team: Priority email support with guaranteed response times.
  • Enterprise: Dedicated Support Engineer and custom SLA contracts.

5. Service Continuity

In the unlikely event that N3MO SaaS shuts down, you are fully protected. Because the N3MO core engine is distributed under a source-available PolyForm Noncommercial license, you will always be able to run the tool locally on your own hardware, completely independent of our servers.
