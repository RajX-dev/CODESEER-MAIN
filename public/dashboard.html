Setup Instructions

  1. Go to your GitHub Repository -> Settings -> Webhooks.
  2. Click Add webhook.
  3. Set Payload URL to: https://api.n3mo.shop/api/webhook
  4. Set Content type to: application/json
  5. Paste your Webhook Secret (from above) into the Secret field.
  6. Select Let me select individual events and check Pull requests.
  7. Click Add webhook. You're done!
